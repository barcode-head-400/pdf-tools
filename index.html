楽譜わけわけv2.1

スキャンした楽譜PDFを、パートごとのファイルに分けて整理するソフト

こんなときに

  • まとめてスキャンした楽譜を、パート譜ごとのPDFに分けたい
  • 見開きでスキャンした楽譜を、1ページずつに切り分けたい
  • 全パートの楽譜に、団名印をまとめて押したい

主な機能

  • PDFやフォルダをドラッグ＆ドロップで読み込み、複数のPDFをまたいでまとめて編集
  • コマごとに「フォルダ」「パート」「No.」を指定し、パート別のファイル名で一括保存
  • ページの結合・空白ページの挿入・並べ替え・回転（90°単位）
  • 左右／上下の半分に分割（見開き楽譜の切り分け）
  • 画像スタンプ（PNG・JPG・BMP）の押印。位置を全コマへ一括反映
  • 作業内容をプロジェクト（.gakufu）として保存し、あとから続きを編集
  • 同名ファイルは上書きせず連番で保存。配色テーマとライト／譜面／ステージの表示モード

書類わけわけv1.1.0

スキャンした書類PDFを、分類・担当部署ごとに分けて整理するオフィス向けソフト

こんなときに

  • 複合機でまとめてスキャンした書類を、案件や部署ごとのPDFに分けたい
  • ファイル名を決まったルール（分類・担当・番号）でそろえて保存したい
  • 承認印や受付印の画像を、複数ページにまとめて押したい

主な機能

  • PDFやフォルダをドラッグ＆ドロップで読み込み、複数のPDFをまたいでまとめて編集
  • ページごとに「分類」「担当・部署」「No.」を指定し、ルールどおりのファイル名で一括保存
  • ページの結合・空白ページの挿入・並べ替え・回転（90°単位）
  • 左右／上下の半分に分割（A3見開きスキャンの切り分け）
  • 画像スタンプ（PNG・JPG・BMP）の押印。数値での位置指定、全ページへの一括反映
  • 作業内容をプロジェクト（.shorui）として保存し、あとから続きを編集
  • 同名ファイルは上書きせず連番で保存。配色テーマとライト／サンド／ダークの表示モード

PDF Mixv2.0

表面だけ・裏面だけでスキャンした2つのPDFを、正しいページ順の1つのPDFにまとめるソフト

こんなときに

  • 両面スキャンができないスキャナーで、両面原稿を表→裏の順に片面ずつ読み取った
  • 裏面のPDFが逆順（最後のページから）になってしまっている

使い方

  1. 基準PDF（表面・正順）を選ぶ
  2. 挿入PDF（裏面・逆順）を選ぶ
  3. 保存先を決めて START を押す

表面のPDFを基準に、裏面のPDFを逆順にして1ページずつ交互に差し込みます。結合後のページ順は実行前に画面で確認できます。

インストール方法と注意

インストール

ダウンロードした Setup ファイルを実行し、画面の案内に沿って進めてください。管理者権限は不要です。PDF Mix はインストール不要で、ダウンロードした exe をそのまま実行できます。

「WindowsによってPCが保護されました」と表示されたら

個人が公開しているソフトのため、初回実行時に Windows の SmartScreen が警告を出すことがあります。「詳細情報」→「実行」を選ぶと起動できます。心配な場合は、上記の SHA-256 でファイルが改ざんされていないか確認できます。

アンインストール

Windows の「設定」→「アプリ」→「インストールされているアプリ」から削除できます。PDF Mix は exe ファイルを削除するだけです。
